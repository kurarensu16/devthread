# Understand and status

For `understand`, inspect the repository structure, manifests, relevant docs, project instructions, and Git state. Read only files needed to answer. Separate observed facts from inferences and unknowns. When requested, update `.devthread/PROJECT.md` and `.devthread/ARCHITECTURE.md` without erasing prior approved decisions. Do not change application code.

For `status`, run `python scripts/status.py <target>` for factual counts and eligible tasks, then add a concise account of phase, drift, risks, and next action using current evidence. If the state is invalid, report the validation errors instead of inferring counts from damaged files. The script does not assess implementation quality or calculate a completion percentage.
