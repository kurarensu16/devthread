# Implement

Read the named task, its dependencies, relevant requirements, project instructions, and affected code. Present a scoped plan before material changes. A developer request to implement the task authorizes scoped reversible edits; obtain specific approval for destructive, external, or materially broader actions. Make the smallest changes that satisfy acceptance criteria, run relevant checks, and record exact results. Update evidence and task status honestly. Code changes alone do not make a task `done`; leave it for explicit review of acceptance criteria.
