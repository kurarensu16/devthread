## Reporting another environment

Record host and version, OS, Python version, complete packaging location, discovery behavior, and a representative workflow. Preserve exact passed, failed, and not-run outcomes. Confirm context recovery in a fresh session before describing it as tested.

Python uses the standard library and is intended to be portable. Portability intent alone is not a completed platform test.
