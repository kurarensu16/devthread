## Host conventions

The original DevMap discovery used `.codex/skills/`. [Current OpenAI guidance](https://learn.chatgpt.com/docs/build-skills) lists `.agents/skills/` for project discovery and `~/.agents/skills/` for user discovery. The npm installer exercises copying into these locations, and the renamed user installation is now observed in Codex on Windows. Separate fresh-chat workflow review remains pending.

The [installation guide](/docs/installation/) also describes Codex's built-in `$skill-installer` and Vercel Labs' `npx skills add`. The source is available on GitHub, but those routes have not been exercised with DevThread. Their file installation and fresh-chat discovery need their own checks.

## npm installer and operating systems

[`devthread@0.1.0` is published on npm](https://www.npmjs.com/package/devthread/v/0.1.0) under MIT. The package targets Windows, Linux, and macOS with Node 22+ and no runtime dependencies. Python 3 runs the skill's scripts. Project, global, custom-directory, and dry-run options use native OS paths and preserve existing installations.

## Reporting another environment

Record host and version, OS, Python version, complete packaging location, discovery behavior, and a representative workflow. Preserve exact passed, failed, and not-run outcomes. Confirm context recovery in a fresh session before describing it as tested.

Python uses the standard library and is intended to be portable. Portability intent alone is not a completed platform test.
